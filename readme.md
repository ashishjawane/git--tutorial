# Git Tutorial 🚀

Welcome to my Git Tutorial repository!

This repository contains my practical learning and practice of Git and GitHub. I'm learning how to manage source code, track changes, work with branches, and collaborate using Git.

## 📚 Topics Covered

- Git Installation and Configuration
- Git Repository Initialization (`git init`)
- Git Status (`git status`)
- Adding Files (`git add`)
- Committing Changes (`git commit`)
- Viewing Commit History (`git log`)
- Creating and Switching Branches
- Branch Merging (`git merge`)
- Git Stash (`git stash`)
- Git Tags (`git tag`)
- Remote Repository (`git remote`)
- Pushing Code to GitHub (`git push`)
- Pulling Changes (`git pull`)
- SSH Key Configuration

## 🛠️ Technologies Used

- Git
- GitHub
- VS Code
- Git Bash

## 💻 Basic Git Commands

```bash
git init
git status
git add .
git commit -m "first commit"
git branch
git log --oneline
git remote -v
git push
git pull
```

## 🎯 Objective

The main objective of this repository is to understand Git and GitHub practically and develop good version control practices for software development projects.
